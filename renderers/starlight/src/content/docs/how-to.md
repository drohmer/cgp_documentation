# How-to recipes

Short recipes for common tasks. Each one starts from the scene template, gives the code to add
with the file and the place where it goes, and shows the expected result (most with a live
demo). New to CGP? Start with [Install and compile](get-started/install.md), then
[Draw a mesh with a camera](how-to/draw-a-mesh.md).
